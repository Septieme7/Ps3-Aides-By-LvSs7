Chapitre 4

🕹️ Étape 3 : Cas particuliers des jeux PS2 et PS1

Pour faire fonctionner vos jeux PS2 et PS1, il ne suffit pas de copier les fichiers de jeu. Il faut distinguer deux situations : celle où vous utilisez le CFW Evilnat (comme c'est votre cas) et celle où vous utilisez PS3HEN.

🎮 Jeux PS2 (via CFW Evilnat)

Avec un CFW, la méthode est plus souple qu'avec le HEN. Vous n'avez pas besoin d'encrypter vos ISOs en .BIN.ENC.

  • Format requis : Vous pouvez utiliser directement vos fichiers .ISO (non encryptés).
  • Emplacement : Placez vos fichiers .ISO dans le dossier /dev_hdd0/PS2ISO/ sur le disque dur interne. Les ISOs stockés sur un périphérique USB externe (FAT32) seront automatiquement copiés sur le disque dur de la PS3 au moment du lancement.
  • Fichier de configuration (.CONFIG) : Bien que souvent facultatif, un fichier .CONFIG peut être nécessaire pour certains jeux spécifiques afin d'améliorer la compatibilité ou de corriger des bugs graphiques. webMAN MOD dispose d'une option "Auto CONFIG" qui peut copier automatiquement le fichier de configuration trouvé dans le dossier PS2ISO si l'ISO n'en a pas.

📝 Fichier de configuration PS2 (.CONFIG) : explication claire

Certains jeux PS2 ont besoin d'un fichier de configuration spécial pour mieux fonctionner sur PS3. Ce fichier est séparé de l'ISO et porte un nom très précis.

Exemple concret :

Exemple --> /dev_hdd0/PS2ISO/Grand Theft Auto - San Andreas v2.01.iso
        --> /dev_hdd0/PS2ISO/Grand Theft Auto - San Andreas v2.01.iso.CONFIG
  • Le premier fichier est l'ISO du jeu.
  • Le second est le fichier de configuration associé.

Ce n'est pas l'ISO qui est renommé. L'ISO garde son nom normal. Le fichier .CONFIG est un petit fichier texte créé à côté de l'ISO, dans le même dossier (/dev_hdd0/PS2ISO/).

Règle de nommage : le fichier .CONFIG doit s'appeler exactement comme l'ISO, extension .iso comprise, puis on ajoute .CONFIG à la fin.

  • MonJeu.iso → MonJeu.iso.CONFIG
  • Gran Turismo 4.iso → Gran Turismo 4.iso.CONFIG

À quoi ça sert ? Il permet à webMAN MOD / à l'émulateur PS2 d'appliquer des réglages spécifiques pour ce jeu :

  • choix de l'émulateur (ps2_emu, ps2_netemu, ps2_gxemu…)
  • correctifs de compatibilité
  • gestion de la mémoire
  • correction de bugs graphiques ou de ralentissements
  • forçage de région, etc.

Que faire ?

  • Gardez l'ISO et le .CONFIG côte à côte dans /dev_hdd0/PS2ISO/.
  • Ne renommez pas l'ISO, sinon le .CONFIG ne sera plus associé et le jeu perdra ses réglages.
  • Si le jeu fonctionne bien, ne touchez à rien.
  • Si vous supprimez le .CONFIG, le jeu peut encore démarrer, mais il perdra ses réglages spécifiques et peut présenter des bugs.
💡 Astuce : webMAN MOD dispose d'une option Auto CONFIG qui peut copier automatiquement un .CONFIG trouvé dans PS2ISO si l'ISO n'en a pas. Ici, le fichier est déjà présent : c'est normal et recommandé.

🕹️ Jeux PS1 (via CFW)

Pour les jeux PS1, le fonctionnement est assez direct.

  • Formats supportés : Les formats .ISO, .BIN/.CUE et .IMG/.CCD sont pris en charge. Le fichier .cue (ou .ccd) doit impérativement être à côté du .bin (ou .img) et porter le même nom.
  • Emplacement : Placez vos fichiers de jeu dans le dossier /dev_hdd0/PSXISO/.
  • Émulateur :
    • Par défaut, webMAN MOD utilise l'émulateur ps1_emu.self. Vous pouvez basculer vers ps1_netemu.self via une option dans /setup.ps3 pour une meilleure compatibilité avec certains jeux.
  • BIOS PS1 externe (optionnel) :
    • Le BIOS interne de la PS3 est utilisé par défaut.
    • Pour utiliser un BIOS PS1 externe, placez un fichier nommé ps1_bios.bin dans le dossier /dev_hdd0/tmp/wm_res/. Ce fichier doit être renommé à partir d'un BIOS PS1 officiel (comme SCPH1001.bin).

🎮 Jeux PSP (via CFW)

Contrairement aux jeux PS1 et PS2, les jeux PSP nécessitent l'installation de deux lanceurs obligatoires en plus des fichiers de jeu.

  • Format requis : Uniquement le format .iso. Les formats compressés .cso et .zso ne sont pas supportés.
  • Emplacement : Placez vos fichiers .iso dans le dossier /dev_hdd0/PSPISO/ (ou sur un périphérique USB dans un dossier PSPISO).
  • Lanceurs obligatoires : Les deux lanceurs suivants doivent être installés impérativement tous les deux :
    • PSP Minis Launcher : Pour les jeux PSP au format "Mini".
    • PSP Remasters Launcher : Pour les jeux PSP au format "Remaster" (UMD classiques).
  • Prérequis : Le mode Cobra doit être activé dans votre CFW (activé par défaut sur Evilnat 4.93).
  • Compatibilité : Environ 60% du catalogue PSP est jouable. Consultez la liste de compatibilité avant de transférer un jeu.
💡 Astuce : Après avoir ajouté de nouveaux ISOs PSP, pensez à rafraîchir la liste des jeux dans webMAN MOD pour qu'ils apparaissent dans le sous-menu "PlayStation®Portable" du XMB.

⚠️ Cas particulier : PS3HEN

Si vous étiez amené à utiliser PS3HEN au lieu du CFW, la procédure pour les jeux PS2 serait différente et plus contraignante :

  • Il faudrait encrypter vos ISOs PS2 au format .BIN.ENC.
  • Les jeux devraient être lancés via le PS2 Classics Launcher.
✅ Bonne nouvelle : Cette étape d'encryption n'est pas nécessaire avec votre CFW Evilnat.
Chapitre 5

🔑 Étape 4 : Les fichiers de licence (RAP, RIF, EDAT)

Les fichiers RAP, RIF et EDAT sont des licences nécessaires pour activer les jeux ou DLC téléchargés au format PKG. Sans eux, la PS3 refuse de lancer le contenu.

📜 Le duo RAP / RIF

  • Le fichier .rap est la clé universelle de licence. Il est lié au contenu, mais pas à votre console.
  • Le fichier .rif est la licence personnalisée. Il est généré par votre PS3 à partir du fichier .rap et est ensuite lié à votre compte et à votre console (via votre act.dat). C'est ce fichier .rif que la PS3 utilise pour déverrouiller et lancer le jeu.

🔓 Le fichier EDAT

  • Le fichier .edat (Encrypted Data) est une licence de déblocage utilisée pour activer le contenu complet de jeux ou DLC qui étaient initialement des versions d'essai (les jeux "C00"). Il contient les informations d'activation nécessaires pour transformer une démo en jeu complet, une fois le fichier .rap installé.

📂 Où les placer ?

  • Fichiers .rap : Déposez-les directement dans /dev_hdd0/exdata/.
  • Fichiers .rif : Déposez-les dans /dev_hdd0/home/[VOTRE_ID_UTILISATEUR]/exdata/. L'ID utilisateur est un numéro à 8 chiffres (ex: 00000001).
  • Fichiers .edat :
    • Cas le plus courant : Placez-les dans /dev_hdd0/home/[VOTRE_ID_UTILISATEUR]/exdata/, au même endroit que les fichiers .rif.
    • Cas spécifique (certains DLC) : Placez-les dans le dossier du jeu, aux côtés du fichier EBOOT.BIN :
      • /dev_hdd0/game/[ID_DU_JEU]/USRDIR/
      • ou /dev_hdd0/GAMES/[ID_DU_JEU]/PS3_GAME/USRDIR/
⚠️ Important : Ne mélangez jamais les .rif et .edat avec les .rap dans /dev_hdd0/exdata/. Ils seraient ignorés. Chaque type de fichier a son dossier dédié.
💡 Astuce : Assurez-vous que toutes les extensions sont en minuscules (.rap et non .RAP, .rif et non .RIF, etc.).

⚙️ Installation via PKG

Si vous disposez d'un fichier .pkg contenant les licences (RAP, RIF et/ou EDAT), la méthode la plus simple est de :

  1. Copier le PKG dans /dev_hdd0/packages/.
  2. L'installer via le Gestionnaire de PKG du XMB.
  3. Laisser webMAN MOD placer automatiquement les fichiers aux bons endroits.

  • ❌ Ne déversez jamais une collection complète de .rap (ex : 28 768 fichiers) dans /dev_hdd0/exdata/.

  • 🐌 La PS3 devient extrêmement lente dès qu'elle liste ce dossier.
  • 🧊 Le XMB se fige ou met plusieurs minutes à répondre.

  • 🔄 webMAN MOD et multiMAN peuvent planter en scannant le dossier.
  • 🚫 La console peut refuser de démarrer correctement.
⚠️ /dev_hdd0/exdata/ n'est PAS une bibliothèque de licences. C'est un dossier de travail qui doit rester léger, propre et organisé.

Chapitre 7

🚀 Étape 5 : Lancer le transfert

  1. Connexion : Cliquez sur "Connexion" dans FileZilla.
  2. Navigation : Dans le volet de droite (PS3), ouvrez le dossier correspondant à votre jeu (ex: dev_hdd0/GAMES).
  3. Glisser-Déposer : Depuis le volet de gauche (votre PC), faites glisser le dossier ou le fichier ISO vers le volet de droite.
  4. Patience : Le temps de transfert dépend de la taille du jeu et de votre connexion (Ethernet direct = 20-30 Mo/s).

🔍 Astuce FileZilla : Filtre par type de fichier

Pour n'envoyer que les .rap (ou tout autre type) et éviter les erreurs :

  1. Menu Vue > Filtres de nom de fichier…
  2. Cliquez sur Ajouter un filtre et tapez *.rap dans le champ.
  3. Validez. FileZilla ne montrera alors que les fichiers correspondants.

⚡ Optimisation : Forcer le Full-Duplex 1000BASE-T sur la PS3

Pour gagner du temps lors des transferts FTP, il est essentiel de forcer la PS3 à négocier une connexion Gigabit Ethernet (1000BASE-T) en Full-Duplex. Par défaut, la PS3 peut parfois se contenter du 100 Mbit/s, ce qui divise la vitesse par 10.

🛠️ Configuration sur la PS3

  1. Sur le XMB, allez dans Paramètres > Paramètres réseau > Réglages de connexion Internet.
  2. Choisissez Personnalisé.
  3. Sélectionnez Connexion filaire.
  4. Pour l'option Vitesse et Duplex, choisissez 1000BASE-T Full-Duplex.
    • Si cette option n'est pas disponible ou échoue, essayez Détection automatique.
  5. Pour le reste (Adresse IP, DHCP, DNS, MTU), laissez sur Automatique ou Ne pas définir si vous n'avez pas de configuration spécifique.
  6. Sauvegardez et testez la connexion.

📡 Côté PC et réseau

  • Câble : Utilisez un câble Cat5e ou Cat6 (le Cat5 ne supporte pas le Gigabit).
  • Carte réseau PC : Votre carte réseau doit supporter le Gigabit et être configurée en négociation automatique ou 1000BASE-T Full-Duplex.
  • Switch/Routeur : Si vous passez par un routeur, il doit être Gigabit. En connexion directe PC-PS3, aucun switch n'est nécessaire.

⚠️ Limites à connaître

  • Même en Gigabit, le débit maximal vers le disque dur interne de la PS3 est limité à environ 19-21 Mo/s par l'interface SATA 1.5 Gbps.
  • Un SSD interne peut légèrement améliorer les temps d'accès, mais la limite SATA reste la même.
  • Pour FileZilla, vous pouvez aussi passer en mode Actif (Édition > Paramètres > FTP > Mode de transfert) si le mode passif pose problème.
Chapitre 8

✅ Étape 6 : Finalisation sur la PS3

Une fois le transfert à 100% terminé :

  • Retournez sur le XMB de votre PS3.
  • Lancez webMAN MOD et faites une rescan (ou actualisez la liste des jeux) pour que les nouveaux titres apparaissent.
  • Si vous utilisez multiMAN, actualisez simplement la liste des jeux dans l'onglet correspondant.

📂 Où placer vos fichiers pour chaque type de contenu

1. Jeux PS3 (Dossier / JB)

Les fichiers ICON0.PNG, ICON1.PAM, PIC0.PNG, PIC1.PNG et SND0.AT3 doivent être placés à la racine du dossier du jeu, c'est-à-dire au même niveau que le dossier PS3_GAME.

  • Chemin : /dev_hdd0/GAMES/[ID_DU_JEU]/

2. Jeux PS3, PS2, PSX, PSP (ISO)

Pour les jeux au format ISO, la personnalisation se fait via une image de couverture (.jpg ou .png) qui porte exactement le même nom que le fichier ISO (sans l'extension). Cette image sera utilisée comme ICON0.PNG par webMAN MOD.

  • Exemple : Pour un jeu MonJeu.iso dans /dev_hdd0/PS3ISO/, l'icône doit être /dev_hdd0/PS3ISO/MonJeu.jpg (ou .png).
  • Cette méthode fonctionne également pour les jeux PS2, PSX et PSP dans leurs dossiers respectifs (PS2ISO, PSXISO, PSPISO).

3. Applications (webMAN MOD, multiMAN, Apollo, PSP Launchers, etc.)

Chaque application a son propre dossier dans /dev_hdd0/game/. Pour modifier son icône, il faut remplacer le fichier ICON0.PNG à la racine de son dossier d'installation.

🖼️ Gestion des icônes de dossiers et de disques dans webMAN MOD

webMAN MOD utilise des icônes spécifiques pour ses dossiers (PS3, PS2, PS1, etc.). Vous pouvez les remplacer en plaçant vos propres fichiers .png ou .jpg dans le dossier suivant :

  • Chemin : /dev_hdd0/tmp/wm_icons/
  • Les fichiers doivent porter le nom exact de l'icône qu'ils remplacent (ex: folder_ps3.png).

🎬 Gestion des icônes et arrière-plans dans multiMAN

Dans multiMAN, les icônes et arrière-plans de la liste des jeux peuvent être modifiés en remplaçant les fichiers dans des dossiers spécifiques du cache de l'application.

  • Icônes des jeux : /dev_hdd0/game/BLES80608/USRDIR/cache/net/
  • Arrière-plans : /dev_hdd0/game/BLES80608/USRDIR/cache/

🖼️ Ajouter des fonds d'écran personnalisés via USB (méthode simple)

Pour ajouter rapidement des images personnelles comme fond d'écran sur votre PS3, la méthode par clé USB est la plus directe et fonctionne parfaitement, même sans FTP. Elle est idéale pour un usage ponctuel.

  1. Préparez une clé USB : formatez-la en FAT32.
  2. Créez un dossier PICTURE à la racine de la clé (en majuscules).
  3. Copiez vos images dans ce dossier. La PS3 supporte officiellement les formats suivants : JPEG (DCF 2.0/Exif 2.21), PNG, GIF, TIFF, BMP et MPO (photos 3D au format MP). Pour un rendu optimal sur un écran HD, privilégiez des images en 1920x1080.
  4. Branchez la clé sur la PS3, puis allez dans la colonne Photo du XMB.
  5. Sélectionnez la clé USB, choisissez une image, appuyez sur Triangle et sélectionnez « Copier ». L'image sera enregistrée dans le stockage interne de la PS3 (dossier Photo). Vous pourrez ensuite la retrouver à tout moment dans la colonne Photo et la définir comme fond d'écran via Triangle > « Définir comme fond d'écran », sans avoir à rebrancher la clé USB.
💡 Si la PS3 n'affiche pas les images : placez le curseur sur l'icône de la clé USB (sans appuyer sur X), appuyez sur Triangle et choisissez « Afficher tout ». Cette commande force la PS3 à afficher tous les fichiers compatibles, où qu'ils soient sur le périphérique.
⚠️ Astuce : Cette méthode ne remplace pas les thèmes .p3t complets, mais elle est parfaite pour un fond d'écran personnel. Pour un thème complet, utilisez l'installation classique via /dev_hdd0/theme/ ou le gestionnaire de thèmes du XMB.

🌡️ Étape 8 : Configuration de webMAN MOD (Température & Ventilation)

webMAN MOD offre un contrôle précis de la ventilation pour protéger votre console. La configuration se fait via l'interface /setup.ps3 (voir section IP ci-dessous).

🎛️ Les 5 modes de ventilation

ModeDescriptionAvantagesInconvénients
SYSCONLe système gère le ventilateur automatiquement.Stable, aucun risque de conflit.Refroidissement moins agressif.
DYNAMIC (AUTO)webMAN ajuste la vitesse pour atteindre une température cible (68°C par défaut).Refroidissement puissant et efficace.Peut être bruyant ("effet avion") sur les jeux exigeants.
AUTO #2Algorithme plus doux, la vitesse augmente progressivement avec la température.Évite l'effet "avion" et les variations brusques.Moins efficace pour refroidir rapidement.
MANUALVous fixez une vitesse de ventilateur constante (35% par défaut).Silencieux si vitesse basse.Ne s'adapte pas à la charge, risque de surchauffe.
PS2 ManualVitesse fixe spécifique pour les jeux PS2.Refroidissement dédié aux jeux PS2.Non applicable aux jeux PS3.

🌡️ Plages de température recommandées

  • Normale : Entre 65°C et 75°C.
  • À éviter : Au-dessus de 75°C pendant de longues périodes peut endommager les composants à long terme.
  • Température cible DYNAMIC : Réglez entre 68°C et 72°C. Une valeur basse (65°C) = plus bruyant mais plus protecteur. Une valeur haute (75°C) = plus silencieux mais moins efficace.
  • Vitesse max : Par défaut 80%, modifiable entre 40% et 99%.
  • Vitesse min : Par défaut 25%, modifiable entre 20% et 95%.

🎮 Raccourcis manette en jeu

  • SELECT + HAUT/BAS : Ajuster la vitesse manuelle du ventilateur.
  • SELECT + GAUCHE/DROITE : Changer la température cible (mode DYNAMIC).
  • L2 + R2 + △ : Afficher la température CPU/RSX.

💡 Conseils pratiques

  • Si votre PS3 est un modèle "Fat" ou si la pâte thermique est ancienne, privilégiez le mode DYNAMIC ou AUTO #2.
  • Le mode SYSCON est le plus sûr si vous ne voulez pas vous soucier de la configuration.
  • Pour les jeux PS2, une vitesse de 40% est recommandée.

🔧 Étape 9 : Les Syscalls (CFW Syscalls)

Les syscalls sont des appels système qui permettent à webMAN MOD d'accéder à des fonctions normalement réservées au firmware officiel (comme le montage de jeux, la lecture de la température, etc.).

🔑 Syscalls importantes utilisées par webMAN MOD

SyscallFonctionUtilisation
Syscall 8Montage de jeux (Cobra/Mamba)Monte les ISOs et dossiers de jeux.
Syscall 383Lecture de la températureLit les températures CPU/RSX.
Syscall 389Contrôle du ventilateurAjuste la vitesse du ventilateur.
Syscall 0x1337Détection PS3HENDétecte si PS3HEN est actif.

⚠️ Quand les désactiver ?

  • Pour jouer en ligne : Désactiver les syscalls CFW peut réduire les risques de bannissement sur le PSN. webMAN MOD permet de les désactiver au démarrage via l'option "Disable CFW syscalls" dans /setup.ps3.
  • Attention : Désactiver les syscalls CFW désactive également le contrôle dynamique du ventilateur de webMAN MOD. Dans ce cas, le ventilateur reste sur le dernier réglage appliqué.
  • Pour réactiver les syscalls : Allez dans Custom Firmware Tools et cherchez l'option "Allow re-enable syscalls". Vous pouvez aussi utiliser le combo R2 + △ pour restaurer les syscalls CFW.

💡 Bonnes pratiques

  • Si vous ne jouez pas en ligne, laissez les syscalls activés pour profiter du contrôle complet de webMAN MOD.
  • Si vous jouez en ligne, désactivez les syscalls avant de lancer le jeu, mais sachez que vous perdez le contrôle dynamique du ventilateur.
  • Pour les jeux PS2, les syscalls doivent rester activés pour que le montage des ISOs fonctionne.

🔐 Étape 11 : Gestion du mot de passe FTP (root)

Le nom d'utilisateur FTP par défaut sur PS3 est presque toujours root. Le mot de passe, lui, dépend de l'application qui fournit le serveur FTP. Il est important de comprendre que chaque application gère son propre mot de passe : modifier celui de webMAN MOD n'affecte pas multiMAN, et inversement.

📂 Où se trouve le mot de passe ?

ApplicationFichier de mot de passeImpact d'un changement
webMAN MOD/dev_hdd0/tmp/wmtmp/password.txtChange uniquement le mot de passe FTP de webMAN MOD.
multiMAN / OpenPS3FTP/dev_hdd0/game/OFTP00001/USRDIR/passwordChange le mot de passe FTP utilisé par multiMAN et les serveurs basés sur OpenPS3FTP.
Apollo Save ToolAucun serveur FTP completAucun impact : Apollo n'expose pas de serveur FTP root.
💡 À savoir : Le nom d'utilisateur reste root. Si le fichier password est vide, la connexion se fait sans mot de passe.

🛠️ Comment changer le mot de passe de webMAN MOD ?

  1. Connectez-vous à votre PS3 avec FileZilla.
  2. Naviguez jusqu'au dossier /dev_hdd0/tmp/wmtmp/.
  3. Téléchargez le fichier password.txt sur votre PC.
  4. Ouvrez-le avec un éditeur de texte (Bloc-notes, Notepad++…), remplacez son contenu par votre nouveau mot de passe, puis enregistrez.
  5. Renvoyez le fichier password.txt sur la PS3, dans le même dossier, en écrasant l'original.
  6. Redémarrez la PS3 ou quittez puis relancez webMAN MOD pour que le changement soit pris en compte.

🛠️ Comment changer le mot de passe de multiMAN / OpenPS3FTP ?

  1. Connectez-vous à votre PS3 avec FileZilla.
  2. Naviguez jusqu'au dossier /dev_hdd0/game/OFTP00001/USRDIR/.
  3. Téléchargez le fichier password sur votre PC.
  4. Ouvrez-le, remplacez son contenu par votre nouveau mot de passe, puis enregistrez.
  5. Renvoyez le fichier password sur la PS3, dans le même dossier, en écrasant l'original.
  6. Redémarrez la PS3 ou quittez puis relancez multiMAN pour que le changement soit pris en compte.

⚠️ Points importants

  • Indépendance des mots de passe : Si vous utilisez à la fois webMAN MOD et multiMAN, vous pouvez avoir deux mots de passe différents. FileZilla vous demandera celui correspondant au serveur FTP actif.
  • Profils FileZilla : Créez deux sites dans le Gestionnaire de sites de FileZilla (un pour webMAN MOD, un pour multiMAN) si vous changez souvent de serveur.
  • Mot de passe admin webMAN MOD : Il existe aussi un mot de passe pour le mode administrateur de l'interface web de webMAN MOD. Ce n'est pas le mot de passe FTP root. Il se définit via l'URL http://[IP-PS3]/admin.ps3?enable&pwd=VOTRE_MOT_DE_PASSE.

🔄 Étape 12 : Différence entre les révisions "Q", "S" et "T" de webMAN MOD

Si vous avez déjà téléchargé une version 1.47.48, vous avez peut-être remarqué les lettres q, s ou t à la fin. Il ne s'agit pas de versions différentes, mais de révisions successives d'une même branche. La version t est la plus récente et la plus complète.

📜 Historique des révisions 1.47.48

RévisionDate de sortieNouveautés et correctifs principaux
1.47.48q29 juillet 2026Support explicite des firmwares 4.92 et 4.93, corrections de bugs mineurs (parsing des chaînes hexadécimales, commandes PS3MAPI).
1.47.48sFin août 2026Correctif majeur : répare la régression qui cassait la compatibilité FTP avec FileZilla. Ajoute également des correctifs pour les dossiers réseau et la détection qCFW.
1.47.48t20 septembre 2026Inclut tous les correctifs de la s, plus : répare les liens GitHub cassés (couvertures en ligne et téléchargements de homebrews), ajoute le support de l'overclocking du second canal mémoire RSX, et corrige divers autres bugs (erreur 501 sur FTP, options "NET folders"...).

🎯 Laquelle choisir ?

Pour une utilisation avec CFW Evilnat 4.93 et FileZilla, la réponse est sans hésiter la version 1.47.48t.

💡 En résumé : t est une mise à jour de s, qui est elle-même une mise à jour de q. Si vous êtes sur la q ou la s et que vous avez des problèmes de FTP, la t est la solution directe.

🎮 Étape 14 : Résoudre l'erreur 80028F10 (Jeux PS1)

L'erreur 80028F10 (« Impossible de lire ce jeu selon le réglage de sortie vidéo actuel ») est très fréquente avec les jeux PS1. Elle survient principalement à cause d'un conflit entre la résolution 720p et l'émulateur PS1.

🎯 Solution : Désactiver la résolution 720p

  1. Allez dans Paramètres > Paramètres d'affichage > Paramètres de sortie vidéo.
  2. Sélectionnez votre type de connexion (HDMI, etc.).
  3. Choisissez Personnalisé (et non Automatique).
  4. Décochez impérativement la case 720p.
  5. Laissez cochées 1080p et 1080i. Pour un jeu PAL, laissez 576p ; pour un jeu NTSC, laissez 480p.
  6. Validez et relancez le jeu.
💡 Pourquoi ça marche ? L'émulateur PS1 de la PS3 a un bug connu avec la résolution 720p. En la désactivant, on force la PS3 à négocier un mode d'affichage que le jeu accepte.

⚙️ Solutions complémentaires

  • Désactiver le lissage : Allez dans Paramètres > Paramètres du jeu > Paramètres PS/PS2 et mettez Lissage sur Désactivé.
  • Ajuster le mode d'affichage : En jeu, appuyez sur le bouton PS, allez dans Autres paramètres > Paramètres PS/PS2 et essayez de passer le Mode d'affichage de Plein écran à Normal.
  • Vérifier la région : L'erreur est aussi fréquente avec les jeux PAL (50 Hz) sur une PS3 NTSC (60 Hz). La désactivation du 720p résout souvent ce problème.

📌 À retenir

  • Si vous devez réactiver la 720p pour d'autres jeux PS3, pensez à la redécocher pour les jeux PS1 problématiques.
  • Laisser la 720p décochée en permanence est une solution viable, la plupart des jeux PS3 modernes s'en passent très bien.

🚑 Dépannage rapide

❌ Erreur : "Invalid character sequence received"

Solution : Retournez dans le Gestionnaire de sites de FileZilla (onglet Jeu de caractères) et assurez-vous que "Forcer l'UTF-8" est bien sélectionné. Si le problème persiste, essayez l'option "Utiliser un jeu de caractères personnalisé" et tapez UTF8. Pensez aussi à mettre à jour webMAN MOD en version 1.47.48t.

❌ Le jeu n'apparaît pas sur la PS3
  • Solution 1 : Vérifiez que le dossier du jeu est bien placé dans dev_hdd0/GAMES/ et non ailleurs.
  • Solution 2 : Vérifiez que le dossier contient bien le fichier PS3_DISC.SFB et le dossier PS3_GAME à la racine.
  • Solution 3 : Redémarrez la PS3 pour forcer la reconstruction de la base de données des jeux.
❌ Le jeu PS2 ne se lance pas (sous CFW)

Solution : Vérifiez que votre ISO est bien non encrypté et placé dans /dev_hdd0/PS2ISO/. Si un jeu spécifique bug, cherchez un fichier .CONFIG correspondant et placez-le à côté de l'ISO. Le .CONFIG doit porter exactement le nom de l'ISO suivi de .CONFIG (exemple : Grand Theft Auto - San Andreas v2.01.iso.CONFIG).

❌ Le jeu PS1 ne se lance pas
  • Solution 1 : Vérifiez que le fichier .cue est bien à côté du .bin avec le même nom.
  • Solution 2 : Essayez de basculer l'émulateur en ps1_netemu.self dans /setup.ps3.
  • Solution 3 : Désactivez la résolution 720p (voir Étape 14).
❌ Erreur 80028F10 sur un jeu PS1

Solution : Voir Étape 14 — désactivez la résolution 720p dans les paramètres d'affichage.

❌ La connexion FTP échoue

Solution : Vérifiez que le pare-feu Windows ne bloque pas FileZilla. Essayez de passer en mode "Actif" dans les paramètres de FileZilla ou désactivez temporairement le pare-feu.

❌ Je ne peux plus me connecter en FTP après avoir changé le mot de passe
  • webMAN MOD : /dev_hdd0/tmp/wmtmp/password.txt
  • multiMAN / OpenPS3FTP : /dev_hdd0/game/OFTP00001/USRDIR/password

Redémarrez la PS3. Si besoin, videz le fichier password pour revenir à une connexion sans mot de passe.

❌ Le jeu PSN ne se lance pas malgré le PKG installé

Solution : Vérifiez que le fichier .rap est bien présent dans /dev_hdd0/exdata/, que les fichiers .rif et .edat sont dans /dev_hdd0/home/[VOTRE_ID]/exdata/, et que toutes les extensions sont en minuscules. Pour certains DLC, vérifiez que le fichier .edat est aussi dans le dossier USRDIR du jeu.

❌ Les ventilateurs sont bloqués à 100% ou la PS3 s'éteint

Solution : Allez dans /setup.ps3, sélectionnez SYSCON, sauvegardez et redémarrez la console. Si le problème persiste, supprimez le fichier /dev_hdd0/tmp/wm_config.bin et redémarrez.

❌ NPS Browser ne trouve pas les jeux

Solution : Vérifiez que les URL TSV sont bien renseignées et que vous avez cliqué sur "Sync now" dans les options. Assurez-vous que votre pare-feu ne bloque pas NPS Browser.

❌ pkg2zip échoue à l'extraction

Solution : Vérifiez que le chemin de pkg2zip.exe est correct dans les options et que les paramètres sont bien -x {pkgFile} "{zRifKey}".

🚀 Overclocking RSX avec Cobra 8.5 (Spécifique)

Cobra 8.5 introduit une nouvelle méthode d'overclocking du RSX qui peut être appliquée au démarrage de la console.

📝 Fichier overclock.txt

Pour overclocker le RSX de manière persistante, créez un fichier nommé overclock.txt et placez-le à la racine d'une clé USB ou dans le disque interne (/dev_hdd0/).

Contenu du fichier :

700
850
  • La première ligne correspond à la fréquence du cœur (Core) en MHz.
  • La seconde ligne correspond à la fréquence de la mémoire (Memory) en MHz.

Fréquences supportées :

  • Core : 300 MHz à 1050 MHz (par "pas" de 50 MHz).
  • Memory : 300 MHz à 1050 MHz (par "pas" de 25 MHz).
⚠️ Avertissement : Un overclocking trop élevé peut causer des instabilités, des freezes, des artefacts graphiques, voire endommager le RSX. Testez progressivement et surveillez les températures. Si la console ne démarre pas, retirez le fichier overclock.txt.
Chapitre 23

📐 Comprendre les « pas » de fréquence (Core et Memory) du RSX

Lorsque vous overclockez le RSX de votre PS3 via Cobra 8.5, vous ne pouvez pas choisir n'importe quelle fréquence. Chaque composant (Core et Memory) possède un pas (ou step), c'est-à-dire l'incrément minimum entre deux valeurs autorisées. Toute valeur qui ne respecte pas ce pas sera ignorée ou arrondie par Cobra.

🎯 Core (cœur du RSX)

  • Valeur d'origine (stock) : 500 MHz
  • Pas : 50 MHz
  • Plage : 300 MHz à 1050 MHz

Cela signifie que les seules valeurs autorisées pour le Core sont :

300, 350, 400, 450, 500, 550, 600, 650, 700, 750, 800, 850, 900, 950, 1000, 1050

Chaque valeur est espacée de 50 MHz exactement. Vous ne pouvez pas entrer 575 ou 625, car ce ne sont pas des multiples de 50.

🎯 Memory (mémoire du RSX)

  • Valeur d'origine (stock) : 650 MHz
  • Pas : 25 MHz
  • Plage : 300 MHz à 1050 MHz

Cela signifie que les seules valeurs autorisées pour la Memory sont :

300, 325, 350, 375, 400, 425, 450, 475, 500, 525, 550, 575, 600, 625, 650,
675, 700, 725, 750, 775, 800, 825, 850, 875, 900, 925, 950, 975, 1000, 1025, 1050

Chaque valeur est espacée de 25 MHz exactement. C'est un pas plus fin que pour le Core, ce qui permet un réglage plus précis.

💡 Pourquoi des pas différents ?

Le Core et la Memory du RSX sont deux composants distincts avec leurs propres contraintes matérielles (multiplicateurs de fréquence, PLL interne, etc.). Le Core se règle par grands paliers (50 MHz), tandis que la Memory tolère des ajustements plus fins (25 MHz). C'est une limitation physique du matériel, pas un choix arbitraire.

⚠️ Valeurs invalides : que se passe-t-il ?

Si vous entrez une valeur qui ne respecte pas le pas, Cobra l'ignorera ou l'arrondira à la valeur valide la plus proche. Exemple :

725   <- invalide pour le Core (pas un multiple de 50)
875   <- valide pour la Memory (multiple de 25)

Dans ce cas, 725 pour le Core sera probablement arrondi à 700 ou 750, et 875 pour la Memory sera accepté tel quel.

📌 En résumé

  • « Par pas de 50 MHz » : vous ne pouvez choisir que des valeurs espacées de 50 en 50 (300, 350, 400, etc.).
  • « Par pas de 25 MHz » : vous ne pouvez choisir que des valeurs espacées de 25 en 25 (300, 325, 350, etc.).
  • Toute valeur qui ne respecte pas ce pas sera ignorée ou arrondie par Cobra.
  • Respecter ces pas est obligatoire pour que votre overclocking soit appliqué correctement.
