## 📖 À propos

Ce projet est un guide web interactif, rassemblant toutes les étapes pour préparer, transférer et faire fonctionner vos jeux et licences sur PS3 via FTP, ainsi que configurer webMAN MOD, NPS Browser, Rusty-PSN, PySN et les outils Custom Firmware.

Le guide est **bilingue FR / EN** avec un sélecteur de langue dans l'en-tête.

## ✨ Fonctionnalités

- 📱 **100% responsive** (mobile, tablette, desktop)
- 🌗 **Thème clair / sombre** avec mémorisation du choix
- 📑 **Table des matières latérale** avec scroll-spy
- 🔍 **Recherche instantanée** dans tout le guide (`Ctrl+F` pour l'ouvrir)
- 🌐 **Bilingue FR / EN** avec sélecteur de langue
- 🎨 **Fond animé personnalisable** (orbes lumineux)
- 📊 **Barre de progression de lecture**
- ⬆️ **Bouton retour en haut**
- 🎾 **Image rebondissante décorative** (style DVD-screensaver)
- 📲 **PWA Ready** (installable sur mobile grâce au manifest)
- 📋 **Copie au clic** des adresses DNS et chemins

## 🚀 Utilisation

### Option 1 : En local

1. Clone le dépôt :
   ```bash
   git clone https://github.com/Septieme7/Ps3-Aides-By-LvSs7.git
   ```

2. Ouvre `index.html` dans un navigateur.
